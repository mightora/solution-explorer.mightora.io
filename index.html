    Analysis notes & limitations

      Frequently asked questions

      Does the explorer send my solution ZIP to a server?

      No. The application processes files in your browser memory. The online edition loads interface resources from CDNs; the offline edition does not make external requests.

      Does it support managed and unmanaged solutions?

      Yes. Standard exported Dataverse solution ZIPs can be analysed regardless of managed state. Some metadata may be absent in managed exports, and the explorer surfaces warnings where appropriate.

      How does it compare two solution versions?

      It matches discovered components by type and logical name, and compares extracted metadata properties. It does not perform a semantic analysis of JavaScript, formulas or all flow actions.

      Can this convert a managed solution into an unmanaged one?

      No. Microsoft does not support direct conversion via SolutionPackager or changing an archive flag. The recovery assessment provides a checklist for obtaining the original unmanaged source or documenting an authorised rebuild.

      Can I upload an unpacked YAML solution?

      Not fully yet. The current parser targets XML-based exported solution ZIPs. A ZIP of YAML source-control files will show a coverage warning and may provide an incomplete inventory.

      LOCAL & EDITABLE

      Load a solution ZIP or choose a sample to enable technical reports.

      Exports are generated locally in your browser, including when using the offline edition. No solution file is sent to a server.

      What's included in each report?

      One solution: solution landscape, editable table relationships, security and plug-in views, integrations, dependencies, editable form wireframes, Power Automate branching maps, data dictionary and inspection gaps.

      Two solutions: A/B identities; added, removed and changed components; before/after architecture, data, forms, integrations and flow diagrams; property differences, change-impact prompts and metadata limitations.

      Editability: Word uses editable text and structural diagram tables. PowerPoint uses editable native text boxes, shapes and connectors. Very large presentations are bounded and report the export limit; diagrams are not screenshots.

      INSTALL INSIDE POWER APPS

      Solution Explorer for model-driven apps

      Use the current Dataverse sign-in to discover installed solutions, fully inspect exportable unmanaged packages, and explore installed managed solutions through a clearly labelled partial component inventory. All existing diagrams, comparisons and editable Office reports remain available.

      Dataverse installation ZIP ↓Standalone HTML web resource ↓Installation instructions ↗

      Quick installation: In Power Apps, open an unmanaged solution, create a Webpage (HTML) web resource and upload the HTML file. Save/publish, then edit your model-driven app, add a Web resource page and enable Show in navigation. Save/publish the app. Replace the HTML in the same resource to upgrade.

      Permissions and completeness: Your signed-in user's Dataverse permissions determine which solutions can be listed or exported. Microsoft doesn't allow exporting installed managed or Default solutions, so these show component references rather than complete unpacked files. The downloaded ZIP contains installation files, not an importable Dataverse solution.

      The embedded edition has no Mightora backend, external scripts, tracking or separate login. It requires a live authenticated Dataverse environment; the separate offline edition continues to work without internet access.
